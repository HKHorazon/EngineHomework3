# 基礎遊戲引擎應用｜作業專案

弘光科大「基礎遊戲引擎應用」作業 1–3 共用的 Unity 專案。
三份作業都在這個專案裡做，**只要下載一次**，之後每份作業都直接開同一個專案。

## 下載與開啟

1. 按本頁右上角綠色的 **Code ▸ Download ZIP**
2. 解壓縮
3. 打開 Unity Hub，用 **開啟舊專案**（Add / Open）選剛剛解壓縮出來的資料夾
4. 專案版本是 Unity **6000.3.25f1**

## 繳交

1. 在 Unity 裡 **Ctrl + S** 存檔，然後關掉 Unity
2. 打開專案資料夾（當初解壓縮、用開啟舊專案打開的那個）
3. 同時選取 **Assets、Packages、ProjectSettings** 三個資料夾
4. 按右鍵 ▸ **壓縮為 ZIP 檔案**，檔名改成 `學號_姓名.zip` 後上傳

Library、Temp、Logs 這些資料夾不要放進去，它們很大，Unity 會自己重建。
